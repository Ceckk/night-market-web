# Night Market — web demo

Play it in your browser: https://ceckk.github.io/night-market-web/

A packed Thai night market, and every shopper is hungry for one dish. Tap the glowing shoppers out of the crowd: if a stall is cooking their dish they are served and tip, if not they wait on a bench. Fill all five benches and the lanterns go out. Tips build the market street, stall by stall.

This repository holds only the built game (a Unity Web player), published with GitHub Pages. Works on phones and desktop browsers.
